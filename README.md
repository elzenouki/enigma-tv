# Enigma TV

تطبيق Android TV بيشغّل قنوات رسيفر Enigma2 (OpenWebif) على أي شاشة أندرويد في نفس الشبكة.

**تحميل:** https://github.com/elzenouki/enigma-tv/releases/latest/download/enigma-tv.apk

| الزرار | الوظيفة |
|---|---|
| ▲ / CH+ | القناة اللي بعدها |
| ▼ / CH- | القناة اللي قبلها |
| OK | قايمة الباقات والقنوات |
| ◀ ▶ / Info | معلومات القناة |
| أرقام | رقم القناة مباشرة |
| Menu | الإعدادات (IP / مستخدم / باسورد) |
| رجوع مرتين | خروج |
